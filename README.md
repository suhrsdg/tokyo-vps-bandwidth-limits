## 10Mbps 的“无限流量”一个月到底能跑多少

这是选这台机器时最该算的一笔账。

端口速率换算成月流量很简单：10Mbps 满载约 1.25 MB/s，一天 108GB，30 天约 **3.2TB**。20Mbps 约 6.5TB，30Mbps 约 9.7TB，100Mbps 约 32TB。这些是理论满载值，实际受对端、路由和丢包影响，跑不满是常态。

反过来看流量封顶的那两档。1TB 摊到 30 天是每天 34GB，30Mbps 端口全速跑大约 4 小时就能吃掉一天的额度；20Mbps 端口大约 6 小时。也就是说，“1TB + 30Mbps”这档的实际约束是月总量，不是速度。

对照下来，$9 的 TYO-VP02（不限流量 / 10Mbps）在总量上反而比 TYO-VG04（1TB / 30Mbps）宽松三倍多，代价是峰值速度只有三分之一。每天传输量在 100GB 以内的站、代理、API、监控，10Mbps 那档更划算，而且不用担心某天超量被限速或加收。

真正需要 30Mbps 峰值的场景不多：给几十人同时推流、做软件镜像、跑大批量备份恢复。这些场景又往往会在月底撞上 1TB 的天花板。所以这两档不是“低配和高配”，是两种不同的计费逻辑，按你的流量形态选，不是按价格选。

## 按场景选：五种常见用途对应哪一档

**游戏服务器（Minecraft、Palworld、ARK 这类私服）。** 看延迟和抗攻击，带宽次要。ExtraVM 全系含 Anti-DDoS，延迟口径日本境内 10ms 以内、韩国 30 到 40ms，是这一档里信息最完整的。LightLayer 东京的 10 到 30Mbps 端口跑小规模私服够，人数上去要往更高端口走。

**建站和 API 后端。** 内存和硬盘比端口重要。1GB 内存跑 WordPress 加缓存可以，直接跑数据库会吃紧。要 4GB 就该看 $16 到 $24 那一档，ExtraVM 的 4GB 是 $16、EDIS 的 4GB 是 €21.99、JUSTG 的 4 核 4GB 是 $49.99。

**需要 Windows 远程桌面。** 先确认档位含不含授权，这是最常见的坑。OliveVPS 把这条写得很清楚：$3.99 那档只能 Linux，要 Windows 就得上 Pro 或 Premium，还要付授权附加费。

**需要日本原生 IP。** 这里要分清商家自测和独立验证。JUSTG 官方页面称 2026 年 10 月在东京和首尔节点测过 ChatGPT、Claude、Gemini、Netflix、Disney+ 可解锁，并注明第三方政策可能变化，这是商家自己的测试。2025 年 7 月一份第三方测评对 LightLayer 东京 IP 的结果则比较杂：Netflix 日本、Prime Video 日本可用，Disney+ 判定为 IP 被封，Claude 不可用。同一个 IP 在不同时间、不同检测脚本下结论会变，不建议把流媒体解锁当成购买理由。

**自建 VPN 或代理。** KernelHost 提供 root 权限自己装 WireGuard、OpenVPN，也有一键 AmneziaVPN 的独立方案，500Mbit/s 上行、不限流量。LightLayer 东京的“优化”档如果确实是大陆方向优化，做代理会比国际线路顺手，但优化具体走哪家上游，还是要问客服确认，别自己脑补。

## 什么情况下不该选东京，或者不该选这一档

**要回国 CN2 GIA 优化的。** JUSTG 在自己的东京页面上写得很明确：东京不使用 CN2 GIA，只有莫斯科机房有。这是个有用的排除信息。LightLayer 东京的“优化”档是什么级别，公开信息不足以下结论，按 CN2 GIA 的预期去买大概率会失望。

**要 GPU 跑模型训练的。** 东京这些产品都是纯 CPU。JUSTG 页面直说，CPU 服务器适合 AI 应用、API 调用、bot 和 agent，不适合模型训练。真要 GPU 就得另找产品线。

**必须默认带 IPv6 的。** KernelHost 的 Edge 系列不含 IPv6，其他几家有的含有的不含，LightLayer 未确认。如果你的业务依赖 IPv6，下单前必须先问清楚。

**需要大带宽突发的。** 10 到 30Mbps 做视频分发、镜像源、大文件下载中心都不合适。这类场景要么上 100Mbps 那档，要么换 1Gbps 端口配流量封顶的产品。
